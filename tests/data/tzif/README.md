# TZif test fixtures

Public-domain IANA tzdata 2025b, from Python tzdata 2025.2's pinned wheel.
Generated/extracted reproducibly with Python's standard library only:
`python -I F:\dev-artifacts\runs\maxCron\phase5-20261117-0755\fixtures.py`.
The retained generator and provenance.json record the exact download URL and SHA-256.
The six named regions cover 2026/2027 transitions, southern seasons, 30-minute
changes, two-hour Troll changes, historical midnight changes and footer-driven future years.
`Antarctica/Troll` is extracted from the same pinned wheel by retained
`r2/extract_troll.py`; `r2/troll-provenance.json` records its hash. Alias copies
exercise lookup spelling. Synthetic files are built by that documented script
with Python struct.pack; their names identify RFC layouts or intentional errors.
TestTimeZoneReference.inc was independently computed with isolated Python zoneinfo
from the pinned files, seed 20261117, including transition neighbours and random dates.
No installed timezone package is required to build or run the Delphi tests.

`tzif-fat/Europe/Warsaw` is generated by retained `fat_fixture.py`: it adds a
-2^59-second initial type-0 transition to the pinned slim file. It is a synthetic
fat-layout probe, not a zic fat build; all in-range transitions are unchanged.
